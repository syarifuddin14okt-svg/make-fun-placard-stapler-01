Iron and Regret — a one-line museum placard for a stapler, written as if it were an ancient artifact: "Stapler, c. 1994. Iron and regret. Donated by the Accounts Department after binding the last budget nobody read." (112 characters, inside the 180-character gate.)

## Run it

```sh
python3 main.py
```

Writes the placard to `/output/entry.txt` and reads it back to verify the write is byte-identical.
